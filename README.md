# Лабораторная работа №4 по дисциплине «Базы знаний»

Предметная область: **«Выбор вида кофе для гостя»**.

## Запуск

Требуется Python 3. Дополнительные библиотеки и установка пакетов не нужны.
Из каталога проекта выполните:

```sh
python3 main.py
```

В Windows можно использовать `python main.py`.
В консоли выбирайте ответы, вводя номер варианта: `1` или `2`.
Система задаёт два вопроса и выводит одну рекомендацию.
Если введён другой ответ, система повторно запрашивает номер варианта.

## Факты

Ответы пользователя хранятся в словаре `facts`.

| Факт | Представление в программе |
| --- | --- |
| Гость хочет кофе без молока | `milk = "no"` |
| Гость хочет кофе с молоком | `milk = "yes"` |
| Гость предпочитает маленький объём чёрного кофе | `volume = "small"` |
| Гость предпочитает большой объём чёрного кофе | `volume = "large"` |
| Гость предпочитает много молочной пены | `foam = "much"` |
| Гость предпочитает мало молочной пены | `foam = "little"` |

За один диалог собираются только два факта. Если выбран кофе без молока,
вторым фактом будет объём. Если выбран кофе с молоком — количество пены.

## Правила ЕСЛИ–ТО

1. ЕСЛИ гость хочет кофе без молока И предпочитает маленький объём чёрного кофе, ТО рекомендовать эспрессо.
2. ЕСЛИ гость хочет кофе без молока И предпочитает большой объём чёрного кофе, ТО рекомендовать американо.
3. ЕСЛИ гость хочет кофе с молоком И предпочитает много молочной пены, ТО рекомендовать капучино.
4. ЕСЛИ гость хочет кофе с молоком И предпочитает мало молочной пены, ТО рекомендовать латте.

Функция `infer` последовательно перебирает `RULES` и проверяет совпадение
всех фактов из условия правила. При совпадении возвращается рекомендация.
Эти четыре правила составлены для выбранной предметной области во
исполнение пункта 2 задания; в исходном PDF готовые правила не приведены.

## Контрольные примеры

| Последовательность ответов | Ожидаемая рекомендация |
| --- | --- |
| `2`, `1` | Эспрессо |
| `2`, `2` | Американо |
| `1`, `1` | Капучино |
| `1`, `2` | Латте |

Весь код проекта находится в `main.py`. Программа не содержит импортов
и использует только встроенные средства Python.
